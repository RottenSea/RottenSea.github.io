## 官方仓库和 AUR

Arch Linux 的软件有两个来源：

- **官方仓库**：由 Arch 的维护者打包，用 `pacman` 安装，前面几页装的都是这里的。
- **AUR**（Arch User Repository）：由用户上传的打包脚本（PKGBUILD），在你的电脑上下载、编译、打包，再安装。Chrome、VS Code 这类官方仓库里没有的软件，大多在 AUR 里。

:::caution
AUR 里的包谁都能上传，Arch 官方不审核。装一个不熟悉的包之前，先在 [AUR 网站](https://aur.archlinux.org/)上看看它的投票数、维护者和最近的评论。
:::

<Steps>

1. **装上 Rust 的工具链**

   AUR 助手替你完成下载、编译、安装这几步，用起来和 `pacman` 差不多。下面装的 paru 自己也在 AUR 里，第一次要手动编译安装。

   paru 是用 Rust 写的，编译要用 Rust 的 `cargo`。安装时装的是 rustup，它负责下载和切换 Rust 的工具链，自己不带编译器，先装上稳定版：

   ```sh
   rustup default stable
   ```

   以后自己写 Rust 也用这一套，`rustup update` 更新工具链。

2. **给 Cargo 换国内源**

   编译 paru 时，cargo 要从 crates.io 下载一堆依赖，国内直连很慢，容易超时。换成中科大的镜像：

   ```sh
   vim ~/.cargo/config.toml
   ```

   写入：

   ```toml title="~/.cargo/config.toml"
   [source.crates-io]
   replace-with = 'ustc-sparse'

   [source.ustc-sparse]
   registry = "sparse+https://mirrors.ustc.edu.cn/crates.io-index/"
   ```

3. **编译安装 paru**

   ```sh
   git clone https://aur.archlinux.org/paru.git
   cd paru
   vim PKGBUILD
   ```

   paru 的源码从 GitHub 下载，国内也慢。找到 `source=` 那一行，在 `https://github.com` 前面加上 `https://v4.gh-proxy.org/`，改完是这样：

   ```sh title="PKGBUILD"
   source=("$pkgname-$pkgver.tar.gz::https://v4.gh-proxy.org/https://github.com/Morganamilo/paru/archive/v$pkgver.tar.gz")
   ```

   保存退出后编译安装：

   ```sh
   makepkg -si
   cd .. && rm -rf paru
   ```

   以后用 `paru -S 包名` 装 AUR 里的软件。只输入 `paru`，会把官方仓库和 AUR 里的软件一起更新。

4. **AUR 的包从 GitHub 下载太慢时**

   很多 AUR 包也从 GitHub 下载。用 paru 装的时候，它会先显示 PKGBUILD 的改动，问 `Accept changes? [Y/n]:`。这时先别按键，另开一个终端，改这个包的 PKGBUILD：

   ```sh
   vim ~/.cache/paru/clone/包名/PKGBUILD
   ```

   和上一步一样，在每个 GitHub 链接前面加上 `https://v4.gh-proxy.org/`。保存后回到 paru 的终端按回车，它就按改过的 PKGBUILD 下载。

   改过以后还是没装成功的话，可以直接从这个目录接着编译安装：

   ```sh
   paru -Bi ~/.cache/paru/clone/包名
   ```

</Steps>

## 常用软件

| 用途 | 软件 | 安装命令 | 说明 |
| --- | --- | --- | --- |
| 浏览器 | Google Chrome | `paru -S google-chrome` | Chromium 内核的浏览器。 |
| 编辑器 | Visual Studio Code | `paru -S visual-studio-code-bin` | 微软官方构建的 VS Code。 |
| 文件管理 | Thunar | 安装时已装好 | Xfce 的文件管理器，轻快，不依赖 Xfce 桌面。 |
| 传文件 | LocalSend | `paru -S localsend-bin` | 在局域网里的设备之间传文件。 |
| 系统信息 | fastfetch | 安装时已装好 | 在终端里显示系统和硬件信息。 |
| 等宽字体 | Maple Mono NF CN | `paru -S maplemononl-nf-cn` | 带中文和图标的编程字体，终端和编辑器用。 |
| 鼠标指针 | Breeze | 安装时已装好 | KDE 的指针主题，在 niri 配置的[可选设置](/system/linux/desktop#可选的设置)里换上。 |

### 让 kitty 用 Maple Mono

```sh
vim ~/.config/kitty/kitty.conf
```

```text title="~/.config/kitty/kitty.conf"
font_family Maple Mono NL NF CN Medium
```

保存后，在 kitty 里按 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F5</kbd> 重新加载配置。

## 日常维护

日常维护只有一件事：隔一两周运行一次 `paru`，把整个系统更新到最新。更新前看一眼 [Arch Linux 首页](https://archlinux.org/)的新闻，偶尔会有需要手动处理的更新。

遇到问题，先查 [ArchWiki](https://wiki.archlinux.org/)，niri 和 Noctalia 的问题分别看 [niri 的文档](https://niri-wm.github.io/niri/)和 [Noctalia 的文档](https://docs.noctalia.dev/)。

最后一页设置 [Snapper 快照](/system/linux/snapper)，升级出问题时能退回去。
