下面的命令都在 kitty 里输入。

## 中文显示

<Steps>

1. **生成中文 locale**

   中文字体安装时已经装好了，还要生成中文的 locale：

   ```sh
   sudo vim /etc/locale.gen
   ```

   按 <kbd>/</kbd> 搜索 `zh_CN.UTF-8`，把这一行开头的 `#` 删掉，保存退出，再生成：

   ```sh
   sudo locale-gen
   ```

2. **让桌面用中文**

   系统语言保持英文，这里只让桌面里的程序用中文，命令行不受影响。

   ```sh
   mkdir -p ~/.config/environment.d
   vim ~/.config/environment.d/locale.conf
   ```

   写入：

   ```sh title="~/.config/environment.d/locale.conf"
   LANG=zh_CN.UTF-8
   LANGUAGE=zh_CN:en_US
   ```

   `LANGUAGE` 的意思是先找中文，程序没有中文就用英文。niri 从登录界面启动时会读这个文件，桌面里打开的程序都会用中文。

</Steps>

## 输入法

<Steps>

1. **在 niri 里启动 Fcitx5，并设置环境变量**

   Fcitx5 和拼音输入法安装时已经装好了。

   ```sh
   vim ~/.config/niri/config.kdl
   ```

   在 `spawn-at-startup "noctalia"` 的下一行加上：

   ```kdl title="~/.config/niri/config.kdl"
   spawn-at-startup "fcitx5"
   ```

   再在文件开头加上：

   ```kdl title="~/.config/niri/config.kdl"
   environment {
       XMODIFIERS "@im=fcitx"
       GTK_IM_MODULE "fcitx"
       QT_IM_MODULE "fcitx"
   }
   ```

   `XMODIFIERS` 让只支持 X11 的老程序也能用输入法。另外两行让 GTK 和 Qt 写的程序通过 Fcitx5 自己的模块输入。

   :::note
   原生的 Wayland 程序可以通过 Wayland 自己的输入协议（text-input）用输入法，按 ArchWiki 的 [Fcitx5](https://wiki.archlinux.org/title/Fcitx5) 一页，`GTK_IM_MODULE` 和 `QT_IM_MODULE` 并不是必需的。笔者加上它们，是因为有的程序不设就打不出字，或者候选框的位置不对。遇到问题时，可以用 `fcitx5-diagnose` 检查输入法的环境。
   :::

2. **重新登录**

   按 <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd>，在会话面板里注销，再登录一次。语言和输入法的设置要重新登录才生效。

3. **加上拼音输入法**

   ```sh
   fcitx5-configtool
   ```

   左边是当前启用的输入法。如果里面只有英文键盘、没有拼音，在右边的可用输入法里搜“拼音”（界面是英文时搜 `Pinyin`），选中后把它加到左边，再点应用。左边已经有拼音的话，这一步可以跳过。

4. **试一下**

   打开任意一个能打字的程序，按 <kbd>Ctrl</kbd> + <kbd>Space</kbd> 在英文和拼音之间切换。

</Steps>

中文设置完了。最后一页是[常用软件](/system/linux/apps)。
