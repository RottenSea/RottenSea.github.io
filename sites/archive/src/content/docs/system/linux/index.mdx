## 写在前面

动手之前，笔者想先说三件事。都是个人看法，不想听可以直接跳到[下一节](#三样东西)。

- **这组教程会过时。** Arch Linux 每个月出一版新的安装镜像，安装步骤时有变化，仓库里的软件包也会改名、拆分或被替换。这里的命令不能保证一直有效，遇到对不上的地方，以英文版 ArchWiki 的[安装指南](https://wiki.archlinux.org/title/Installation_guide)为准。
- **会装 Arch Linux 不等于会编程。** 装好 Arch、用熟 Vim 或 Emacs，就像会装 Office、会用 Office，和写程序的能力是两回事。想借装系统真正学点东西，Gentoo 和 LFS（Linux From Scratch）更合适：它们让你看清 Linux 的目录结构，以及软件怎样从源代码编译成能运行的程序。前提是愿意走出舒适区，自己去查、去解决问题。
- **美化和配置没有尽头。** 电脑终归是干活的工具，把大把时间花在调外观、改配置上，是本末倒置。时间很宝贵，留给产出更多的事，留给思考，也留给身边重要的人。

最后，希望你过得幸福快乐。

## 三样东西

这一组教程装出来的系统由三部分组成：

| 部分 | 是什么 |
| --- | --- |
| [Arch Linux](https://archlinux.org/) | 发行版，也就是操作系统本身。 |
| [niri](https://github.com/niri-wm/niri) | 窗口管理器，严格地说是 Wayland 合成器（compositor）：把窗口画到屏幕上，决定每个窗口放在哪。 |
| [Noctalia](https://noctalia.dev/) | 桌面外壳（shell）：状态栏、启动器、通知、锁屏、壁纸、控制中心。 |

**Arch Linux** 装好以后只有一个命令行，你点名要什么软件，它才装什么，没有预装软件，也没有默认的桌面。它是滚动更新的：没有“大版本升级”这回事，软件一直跟着上游更新。官方仓库里没有的软件，大多能在用户维护的 AUR（Arch User Repository）里找到。它的 [ArchWiki](https://wiki.archlinux.org/) 是 Linux 世界里写得最全的文档之一，其他发行版的用户遇到问题也常去查。

**niri** 的窗口排成一条横向的长带。新打开的窗口接在右边，不会把已有的窗口挤小；屏幕放不下时，往左右滚动就能看到别的窗口。纵向是一个个工作区，上下切换。习惯以后，开再多窗口也不会乱成一团。

**Noctalia** 补上 niri 不管的部分。niri 只负责窗口，状态栏、音量和亮度的提示、通知、锁屏这些都要另外装，Noctalia 把它们一次给齐，还能从壁纸里取色，给整个桌面配色。

和 GNOME、KDE 这样的完整桌面比，这一套更轻，也更需要动手：很多设置要写进配置文件。好处是每样东西都是你自己装上的，出了问题知道去哪里找。

## 概要

接下来几页依次是：

1. [准备工作](/system/linux/prepare)：下载 Arch Linux 镜像、做启动 U 盘、腾出硬盘。
2. [安装 Arch Linux](/system/linux/install)：分出 EFI、swap、btrfs 三个分区，一次装好系统和桌面要用的软件，设置语言、用户、休眠和 GRUB。
3. [niri 和 Noctalia](/system/linux/desktop)：在命令行里配好桌面、快捷键、输入法、密钥环和登录界面，再进入桌面。
4. [常用软件](/system/linux/apps)：AUR 助手 paru 和笔者装的软件。
5. [Snapper 快照](/system/linux/snapper)：自动给系统拍快照，出问题时回滚。

系统和桌面都用英文界面，安装时在 `/etc/locale.conf` 里设的是 `en_US.UTF-8`。中文字体和 Fcitx5 拼音输入法也在安装时装好，中文照样能显示、能输入。

:::caution
- 安装时只有黑底白字的命令行，提示全是英文。每一步要敲的命令这里都写出来了，照着敲就行。
- 这组教程把 Arch Linux 装在一整块硬盘上，硬盘上原有的数据会被清空。
- 用 NVIDIA 独立显卡的话，niri 可能会出问题（例如从命令行启动后黑屏），先看 niri 文档的 [NVIDIA](https://niri-wm.github.io/niri/Nvidia.html) 一页。
:::
