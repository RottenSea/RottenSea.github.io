这一页的步骤来自 ArchWiki 的[安装指南](https://wiki.archlinux.org/title/Installation_guide)，按笔者的选择定好了每一处：整块硬盘分成启动分区和系统分区两个区，引导程序用 systemd-boot，网络用 NetworkManager。命令都在 U 盘的安装环境里输入。

## 启动和联网

<Steps>

1. **从 U 盘启动**

   插上 U 盘开机，进入 BIOS，把 U 盘设为第一启动项，保存退出。进入 Ventoy 的菜单后，选中 Arch Linux 的镜像回车，再选 “Arch Linux install medium (x86_64, UEFI)”。

   等一会儿，屏幕上出现 `root@archiso ~ #`，就进入了安装环境。

2. **字太小时，换个大字体（可选）**

   高分辨率的屏幕上，命令行的字可能小得看不清：

   ```sh
   setfont ter-132b
   ```

3. **确认是 UEFI 启动**

   ```sh
   cat /sys/firmware/efi/fw_platform_size
   ```

   输出 `64` 就对了。如果提示文件不存在，说明电脑是用传统的 BIOS 模式启动的，回到 BIOS 里把启动模式改成 UEFI。

4. **连上网络**

   插着网线的话，什么都不用做。

   用 Wi-Fi 的话，输入 `iwctl` 进入 Wi-Fi 工具，提示符会变成 `[iwd]#`，然后依次输入：

   ```sh
   device list
   station wlan0 scan
   station wlan0 get-networks
   station wlan0 connect 你的Wi-Fi名称
   ```

   第一条列出无线网卡，网卡名一般是 `wlan0`，不是的话，把后面三条里的 `wlan0` 换成列出来的名字。最后一条会让你输入 Wi-Fi 密码。连上以后输入 `exit` 退出。

5. **检查网络**

   ```sh
   ping -c 3 archlinux.org
   ```

   看到三行带 `time=` 的回复就是通了。

</Steps>

## 分区

<Steps>

1. **找到要装系统的硬盘**

   ```sh
   lsblk
   ```

   列出来的 `TYPE` 为 `disk` 的就是硬盘，看 `SIZE` 一栏的容量认出要装系统的那块。固态硬盘一般叫 `nvme0n1`，SATA 接口的硬盘和 U 盘叫 `sda`、`sdb`。下面以 `nvme0n1` 为例，你的硬盘名字不一样的话，后面每条命令都要换成你的。

2. **分区**

   ```sh
   cfdisk /dev/nvme0n1
   ```

   cfdisk 是一个文字界面的分区工具，用上下方向键选分区，左右方向键选底部的操作，回车执行。

   - 如果它先问分区表类型（label type），选 `gpt`。
   - 把已有的分区全部删掉：选中分区，选 `Delete`，直到只剩一行 `Free space`。
   - 选 `New`，大小输入 `1G`，建出启动分区。再选 `Type`，类型选 `EFI System`。
   - 选中剩下的 `Free space`，选 `New`，大小直接回车，把剩下的空间全给系统分区。类型保持默认的 `Linux filesystem`。
   - 选 `Write`，输入 `yes` 写入，再选 `Quit` 退出。

   :::caution
   写入以后，这块硬盘上原来的数据就没了。确认选的是对的硬盘，文件已经备份好了。
   :::

   再运行一次 `lsblk`，硬盘下面应该多出两个分区：`nvme0n1p1`（1G）和 `nvme0n1p2`（其余空间）。SATA 硬盘的话是 `sda1` 和 `sda2`。

3. **格式化**

   ```sh
   mkfs.fat -F 32 /dev/nvme0n1p1
   mkfs.ext4 /dev/nvme0n1p2
   ```

   启动分区用 UEFI 要求的 FAT32，系统分区用 Linux 最常见的 ext4。

4. **挂载**

   ```sh
   mount /dev/nvme0n1p2 /mnt
   mount --mkdir /dev/nvme0n1p1 /mnt/boot
   ```

   系统分区挂到 `/mnt`，启动分区挂到它下面的 `/boot`。接下来往 `/mnt` 里装的东西，就是装进了新系统。

</Steps>

## 安装基本系统

<Steps>

1. **换成国内的镜像站**

   ```sh
   nano /etc/pacman.d/mirrorlist
   ```

   在文件最前面加上两行：

   ```text title="/etc/pacman.d/mirrorlist"
   Server = https://mirrors.tuna.tsinghua.edu.cn/archlinux/$repo/os/$arch
   Server = https://mirrors.ustc.edu.cn/archlinux/$repo/os/$arch
   ```

   pacman 按从上到下的顺序找镜像站，排在前面的清华大学和中国科学技术大学镜像站会先用上。<kbd>Ctrl</kbd> + <kbd>O</kbd> 再回车保存，<kbd>Ctrl</kbd> + <kbd>X</kbd> 退出。这个文件稍后会被复制进新系统，以后装软件也走这两个镜像站。

2. **安装软件包**

   Intel 处理器：

   ```sh
   pacstrap -K /mnt base linux linux-firmware intel-ucode sof-firmware networkmanager sudo nano git base-devel pipewire pipewire-pulse wireplumber bluez bluez-utils power-profiles-daemon zram-generator
   ```

   AMD 处理器把 `intel-ucode` 换成 `amd-ucode`。

   | 软件包 | 做什么 |
   | --- | --- |
   | `base`、`linux`、`linux-firmware` | 最基本的系统、Linux 内核和常见硬件的固件。 |
   | `intel-ucode` / `amd-ucode` | 处理器的微码更新，修复处理器的缺陷和安全问题。 |
   | `sof-firmware` | 很多笔记本的声卡要用这个固件才有声音。 |
   | `networkmanager` | 管理网络连接，Noctalia 的网络面板也靠它。 |
   | `sudo` | 让普通用户临时用管理员权限执行命令。 |
   | `nano` | 简单的命令行文本编辑器，后面改配置文件要用。 |
   | `git`、`base-devel` | 以后装 AUR 里的软件要用。 |
   | `pipewire`、`pipewire-pulse`、`wireplumber` | 声音。 |
   | `bluez`、`bluez-utils` | 蓝牙。 |
   | `power-profiles-daemon` | 电源模式（节能、平衡、性能），Noctalia 的控制中心里可以切换。 |
   | `zram-generator` | 在内存里压缩出一块交换空间，不占硬盘。 |

   下载和安装要几分钟，看网速。

3. **生成分区表文件**

   ```sh
   genfstab -U /mnt >> /mnt/etc/fstab
   cat /mnt/etc/fstab
   ```

   `fstab` 告诉新系统开机时把哪个分区挂到哪里。`cat` 显示出来的内容里应该有 `/` 和 `/boot` 两项。

</Steps>

## 设置新系统

<Steps>

1. **进入新系统**

   ```sh
   arch-chroot /mnt
   ```

   提示符变成 `[root@archiso /]#`，接下来的命令都在新系统里执行，就像已经从硬盘启动了一样。

2. **时区**

   ```sh
   ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
   hwclock --systohc
   ```

3. **语言**

   ```sh
   nano /etc/locale.gen
   ```

   按 <kbd>Ctrl</kbd> + <kbd>W</kbd> 搜索，分别找到下面两行，删掉开头的 `#`：

   ```text title="/etc/locale.gen"
   en_US.UTF-8 UTF-8
   zh_CN.UTF-8 UTF-8
   ```

   保存退出后生成，并把系统语言设成英文：

   ```sh
   locale-gen
   echo "LANG=en_US.UTF-8" > /etc/locale.conf
   ```

   Linux 的命令行（TTY）显示不了中文，系统语言设成中文的话，切到命令行时全是乱码。中文先生成好，等到[中文和输入法](/system/linux/chinese)一页再让桌面用中文。

4. **主机名**

   ```sh
   echo "archlinux" > /etc/hostname
   ```

   主机名是这台电脑在网络上的名字，可以换成别的，只能用小写字母、数字和 `-`。

5. **root 密码**

   ```sh
   passwd
   ```

   root 是系统管理员账户。输入两次密码，输入时屏幕上什么都不显示，这是正常的。

6. **日常用的用户**

   ```sh
   useradd -m -G wheel 用户名
   passwd 用户名
   ```

   把 `用户名` 换成你想要的名字（小写字母）。`-m` 给它建用户目录，`-G wheel` 把它加进 `wheel` 组。

   再让 `wheel` 组的用户能用 `sudo`：

   ```sh
   EDITOR=nano visudo
   ```

   找到下面这一行，删掉开头的 `# `：

   ```text title="/etc/sudoers"
   %wheel ALL=(ALL:ALL) ALL
   ```

   保存退出。

7. **内存交换空间**

   ```sh
   nano /etc/systemd/zram-generator.conf
   ```

   写入：

   ```ini title="/etc/systemd/zram-generator.conf"
   [zram0]
   ```

   只写这一行就够了，默认用内存的一半，最多 4 GiB。

8. **开机启动的服务**

   ```sh
   systemctl enable NetworkManager bluetooth power-profiles-daemon systemd-timesyncd
   ```

   依次是网络、蓝牙、电源模式和联网自动校准时间。

9. **安装引导程序**

   ```sh
   bootctl install
   ```

   systemd-boot 会装进启动分区。再写它的设置：

   ```sh
   nano /boot/loader/loader.conf
   ```

   ```text title="/boot/loader/loader.conf"
   default  arch.conf
   timeout  3
   console-mode max
   editor   no
   ```

   开机时显示 3 秒菜单，默认启动 Arch Linux。

10. **添加启动项**

    启动项要写上系统分区的 UUID（每个分区独有的编号）。UUID 很长，不好手抄，先用 `blkid` 把它写进文件：

    ```sh
    blkid -s UUID -o value /dev/nvme0n1p2 > /boot/loader/entries/arch.conf
    nano /boot/loader/entries/arch.conf
    ```

    文件里现在只有一行 UUID，把它改成下面的样子，`options` 一行里换成你的 UUID：

    ```text title="/boot/loader/entries/arch.conf"
    title   Arch Linux
    linux   /vmlinuz-linux
    initrd  /initramfs-linux.img
    options root=UUID=你的UUID rw
    ```

    微码已经打包在 `initramfs-linux.img` 里，不用另写一行。

11. **重启**

    ```sh
    exit
    umount -R /mnt
    reboot
    ```

    屏幕黑掉时拔下 U 盘。

12. **登录**

    重启后看到 `archlinux login:`，输入刚才建的用户名和密码。看到 `[用户名@archlinux ~]$`，基本系统就装好了。下一步装[桌面](/system/linux/desktop)。

</Steps>
