<Steps>

1. **下载 Arch Linux 镜像**

   打开 Arch Linux 的[下载页](https://archlinux.org/download/)。镜像每个月初发布一次，文件名形如 `archlinux-2026.11.01-x86_64.iso`，一千多 MB。

   页面中间的 “HTTP Direct Downloads” 按国家列出了下载镜像站，在 China 下面挑一个，例如清华大学（TUNA）或中国科学技术大学（USTC），点进去下载 `.iso` 文件。国内的镜像站比官方服务器快得多。

2. **做启动 U 盘**

   用 [Ventoy](https://www.ventoy.net/) 做启动 U 盘：把 Ventoy 装进 U 盘以后，直接把 ISO 文件复制进去就能启动。从 Ventoy 的[下载页](https://www.ventoy.net/en/download.html)下载，按它的说明装进 U 盘，再把 Arch Linux 的 ISO 复制到 U 盘里。

   :::caution
   安装 Ventoy 会格式化 U 盘，先把 U 盘里的文件拷出来。
   :::

3. **关闭 Secure Boot**

   Arch Linux 的安装镜像不支持 Secure Boot（安全启动），开着它就启动不了 U 盘。开机时按 <kbd>Del</kbd>、<kbd>F2</kbd> 或 <kbd>F12</kbd> 进入 BIOS（不同设备的按键不一样，可以搜一下你的型号），把 Secure Boot 关掉。

   :::note
   装好以后如果想重新打开 Secure Boot，要先给系统配好签名，见 ArchWiki 的 [Secure Boot](https://wiki.archlinux.org/title/Unified_Extensible_Firmware_Interface/Secure_Boot)。
   :::

4. **备份重要文件**

   安装时会清空整块硬盘，先把要留的文件拷出来，放到 U 盘或者别的硬盘上。

5. **记下网络信息**

   能插网线最省事。只能用 Wi-Fi 的话，记下 Wi-Fi 的名称（SSID）和密码，安装时要在命令行里输入。

6. **确认都准备好了**，接下来开始[安装 Arch Linux](/system/linux/install)。

</Steps>
