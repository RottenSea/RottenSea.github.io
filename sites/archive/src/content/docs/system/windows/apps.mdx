装好系统后，可以按用途从下面挑：

| 用途 | 软件 | 说明 |
| --- | --- | --- |
| 浏览器 | [Google Chrome](https://www.google.cn/chrome/) | Chromium 内核的浏览器。 |
| Office | Microsoft 365 Apps for enterprise | 用 [Office Tool Plus](https://otp.landian.vip/) 下载、安装和激活。 |
| 看图 | [qView](https://interversehq.com/qview/) | 界面极简的开源看图软件，只显示图片本身。 |
| 视频 | [PotPlayer](https://potplayer.tv/) | 支持的格式多，设置项也多的播放器。 |
| 压缩 | [Bandizip 6.29](https://en.bandisoft.com/bandizip/old/6/) | 最后一个没有广告的 Bandizip 版本，装法见下面的说明。 |
| 下载管理 | [Ghost Downloader](https://gd.xychr.com/) | 开源的多线程下载器，支持 HTTP、FTP、BT 和磁力链接，也能解析视频。 |
| 传文件 | [LocalSend](https://localsend.org/) | 在局域网里的设备之间传文件。 |

:::caution[Bandizip 6.29 的装法]
在下载页的下方找 6.29 的下载链接，不要点页面上方的下载按钮，那是新版。

安装到最后一步时，先别点“完成”：去安装目录里把 `Update.exe` 删掉，再点完成。这样第一次启动时就不会检查更新、弹更新窗口。
:::
