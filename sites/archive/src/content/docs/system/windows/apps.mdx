让 Windows 体验变差的，还有大量喜欢弹广告、想办法收钱的软件。下面是笔者整理的 Windows 必装软件：

| 用途 | 软件 | 说明 |
| --- | --- | --- |
| 浏览器 | [Google Chrome](https://www.google.cn/chrome/) | 快速稳定的 Chromium 内核浏览器，比 Microsoft Edge 稳定得多。 |
| Office | Microsoft 365 Apps for enterprise | 用 [Office Tool Plus](https://otp.landian.vip/) 下载、安装和激活。 |
| 看图 | [JPEGView](https://github.com/sylikc/jpegview) | 简洁快速的图片查看器。 |
| 视频 | [PotPlayer](https://potplayer.tv/) | 功能强大的播放器，视频播放一站式解决。 |
| 压缩 | [Bandizip 6.29](https://en.bandisoft.com/bandizip/old/6/) | 最后一个没有广告的 Bandizip 版本，见下面的说明。 |
| 下载管理 | [Neat Download Manager](https://www.neatdownloadmanager.com/index.php/en/) | 免费版的 IDM，支持多线程下载和断点续传。 |
| 传文件 | [LocalSend](https://localsend.org/) | 在局域网里的设备之间传文件。 |

:::caution[Bandizip 6.29 的装法]
在下载页的下方找 6.29 的下载链接，不要点页面上方的下载按钮，那是新版。

安装到最后一步时，先别点“完成”：去安装目录里把 `Update.exe` 删掉，再点完成。这样第一次启动时就不会检查更新、弹更新窗口。
:::
