## 这组教程做什么

电脑出厂装的 Windows 一般是厂商改过的：带着一批厂商自己的管理软件、试用版的杀毒和办公软件，硬盘也常被分成系统盘和数据盘，系统盘只占一小部分。用厂商的一键恢复，这些又会原样装回来。

这组教程从微软官方的镜像装一个干净的 Windows 11 专业版，再调整设置：关掉广告、推荐和遥测，去掉用不上的组件和服务，改掉几个容易误触的默认设置。

## 为什么用专业版

按 <kbd>Win</kbd> + <kbd>R</kbd>，输入 `winver` 回车，可以看到当前 Windows 的版本。出厂装的一般是家庭版（Home）。专业版（Pro）在家庭版的基础上多了组策略编辑器、远程桌面（被控端）、Hyper-V 虚拟机等功能，很多设置也只有专业版能用组策略管理。

## 设置脚本

能用注册表或命令改的设置，都写进了一个 PowerShell 脚本：先列出要改的每一项，确认一次后全部执行。下载和每一项改了什么，见 [Windows setup](https://rottensea.github.io/misc/windows-setup/)。教程里脚本会做的项，手动的做法都折叠起来，只在不用脚本时展开看。

## 概要

1. [准备工作](/system/windows/prepare)：下载镜像和设置脚本，做启动 U 盘，准备驱动。
2. [安装](/system/windows/install)：从 U 盘安装 Windows，跳过联网，创建本地账户。
3. [联网前的设置](/system/windows/offline-setup)：装驱动，运行设置脚本，关启动项，调整搜索。
4. [联网后的设置](/system/windows/settings)：卸载预装软件，加上英语，整理开始菜单，调整脚本做不了的设置。
5. [设置脚本](/system/windows/script)：脚本的用法，以及它改了哪些设置和系统优化。
6. [推荐的软件](/system/windows/apps)：浏览器、Office、看图、视频、压缩、下载和传文件。

:::caution
如果你的设备还在保修期内，自己安装系统后会失去官方的软件保修，硬件保修还在。
:::
