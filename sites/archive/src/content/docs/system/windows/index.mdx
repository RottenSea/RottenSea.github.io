## 你是系统的主人

作为多年的 Windows 老用户，笔者对系统操作早已形成了一套自己的习惯。然而每当帮别人处理电脑问题，面对那些“陌生”的设置，比如 Windows 11 层层折叠的右键菜单、臃肿杂乱的任务栏，总让我有种无力感。

一个有趣的事实：许多 PC 厂商会在出厂的 Windows 里加上大量为自己服务的预装软件和进程，反而让官方原系统更难用。

拿华硕来说，它会在 Windows 上预装下面这些软件（不止这些，也不算驱动）：

| 软件 | 说明 |
| --- | --- |
| MyASUS（华硕管家） | 系统管理与服务中心。 |
| Armoury Crate（奥创智控中心） | 性能控制中心，主要面向 ROG 玩家国度、天选等游戏本。 |
| ASUS AI Recovery | 系统级备份恢复工具，可以创建恢复分区或备份光盘。 |
| ASUS HiPost | 跨设备剪贴板同步和截图分享工具，在华硕设备之间同步剪贴板。 |
| ASUS Splendid Utility | 屏幕色彩调节软件。 |
| ASUS Giftbox | 应用商店的桌面入口，聚合了游戏、娱乐、工具等应用的推荐和下载。 |
| ASUS GlideX / ScreenXpert | 多屏协同和屏幕管理工具。 |
| McAfee Anti virus | 第三方杀毒软件，通常是试用版。 |
| WPS Office | 第三方办公套件，通常是广告版或试用版。 |
| Foxit PhantomPDF | 第三方 PDF 阅读和编辑器，通常是试用版。 |

管家这类软件只吃资源，没有产出；应用商店不知道在模仿什么；窗口管理工具打断了原本流畅的操作；最后三个软件对笔者来说要么没用，要么有更好的替代品。

至于恢复备份工具，我们都能自己重装系统了，用不着它。用官方的一键恢复，恢复完又会装回一堆预装软件。备份自己管就行，无非是把文件从一个地方拷到另一个地方，用不着专门的软件（除非你有特殊需求）。

总的来说，这一大堆预装软件和服务基本没什么用，还占了大量 CPU 和内存。

还有一个严重的问题。厂商为了恢复系统时保留个人数据，一般会把一块硬盘分成系统盘和数据盘两个区，出厂系统的 C 盘可能只有整块硬盘的 **1/3**。而很多用户没有管理个人数据的意识，什么都往 C 盘放，很快就把 C 盘塞满了。

好在 Windows 有一定的可塑性。这几页想和你分享几招，让 Windows 回到顺手、好用的状态。

## 概要

让 Windows 更好用，首先要选对系统。

按 <kbd>Win</kbd> + <kbd>R</kbd>，输入 `winver` 回车，可以看到当前 Windows 的版本。PC 厂商出厂装的一般是 Windows 家庭版（Home），而不是专业版（Pro）。专业版在家庭版的基础上开放了更多可配置的功能，例如组策略编辑器、远程桌面连接（被控端）、Hyper-V 虚拟机，这些对进阶用户都很实用。

Windows 的很多功能可以通过设置或注册表来管理。例如右键菜单可以通过注册表改回旧版，不需要的功能也可以禁用。

所以，一个好用的 Windows，就是去掉厂商定制的纯净原版系统，再加上大量的配置。接下来几页依次是：

1. [准备工作](/system/windows/prepare)：下载镜像、做启动 U 盘、备份、准备驱动。
2. [安装](/system/windows/install)：从 U 盘安装 Windows，跳过联网创建本地账户。
3. [联网前的设置](/system/windows/offline-setup)：鼠标、驱动、启动项、搜索。
4. [联网后的设置](/system/windows/settings)：卸载预装软件，逐项调整 Windows 设置。
5. [用 WinUtil 清理](/system/windows/winutil)：用 Chris Titus Tech 的工具关掉遥测和广告。
6. [常用软件](/system/windows/apps)：笔者装的软件。

全部读完需要一些时间。

:::caution
如果你的设备还在保修期内，重装系统后会失去官方的软件保修，硬件保修还在。不过既然决定了重装，软件上的问题你自己也能解决。
:::
