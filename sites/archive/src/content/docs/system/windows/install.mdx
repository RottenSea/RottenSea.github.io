## 安装 Windows

<Steps>

1. **插入 U 盘，进入 BIOS**

   BIOS（Basic Input Output System，基本输入输出系统）是主板上的固件，电脑开机后最先运行它：它初始化硬件，并决定从哪里启动系统。

   不同设备进入 BIOS 的方式不一样，请搜一下你的设备怎么进，通常是开机时按 <kbd>Del</kbd>、<kbd>F2</kbd> 或 <kbd>F12</kbd>。

   把 U 盘插到电脑上，开机，进入 BIOS。

2. **设置 BIOS**

   在 BIOS 里禁用 Secure Boot（安全启动），再在 Boot Option Priorities（启动顺序）里把 U 盘设为第一位。

3. **保存并退出**

   保存并退出 BIOS 后，电脑会自动重启，从 U 盘启动。

4. **跟着安装程序走**

   - 选择语言和货币格式。
   - 选择“我没有产品密钥”，装好以后再激活。
   - 选择版本时，选 Windows 11 专业版。
   - 阅读许可条款，点击同意。
   - 到了选择安装位置这一步，把除 U 盘（通常在最后）以外的所有硬盘分区都删掉。
   - 删到只剩未分配的空间后，选中你要装系统的那块硬盘（不要选机械硬盘），点击下一步，安装就开始了。

5. **等待安装完成**

   系统重启后，Windows 就装到了系统盘上。之后电脑会从系统盘启动，不再从 U 盘启动，这时可以拔掉 U 盘。后面还要从 U 盘拷文件，一直插着也没问题。

</Steps>

## 欢迎界面

Windows 装好后第一次进入系统，会重启几次做初始化，然后进入欢迎界面。

<Steps>

1. **重启到可以跳过联网的欢迎界面**

   这时还没有无线网卡驱动。可以从 U 盘装驱动再联网登录微软账户，这里用本地账户，不登录微软账户，少上传一些数据。

   在欢迎界面按 <kbd>Shift</kbd> + <kbd>F10</kbd> 打开命令行，输入下面的命令，回车：

   ```powershell
   oobe\bypassnro
   ```

   电脑重启后，就可以跳过联网，创建本地账户了。

2. **走完欢迎界面**

   把所有不必要的数据收集选项都关掉，完成欢迎界面，进入系统。

</Steps>

进入系统后，你可能会觉得画面不太流畅，这是因为显卡驱动还没装。下一步：[联网前的设置](/system/windows/offline-setup)。
