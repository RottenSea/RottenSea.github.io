<Steps>

1. **下载 Windows 镜像**

   前往微软官方的 [Windows 11 下载页面](https://www.microsoft.com/en-us/software-download/windows11)，在页面最下方的“下载 Windows 11 磁盘映像（ISO）”里选好版本和语言，点击下载。下载完成后，你就有了微软官方的 Windows ISO 镜像。

2. **关闭 BitLocker**

   硬盘加密后，不解密就无法访问，所以重装前要先关掉设备加密。

   按 <kbd>Win</kbd> + <kbd>I</kbd> 打开设置，进入 **设置 > 隐私和安全性 > 设备加密**，把“设备加密”的开关关掉。

   :::note
   解密硬盘需要一段时间，请等它完成。如果你的设备没有开启设备加密，可以跳过这一步。
   :::

3. **下载 Ventoy**

   Ventoy 是一款免费开源的启动 U 盘制作工具。装一次之后，直接把 ISO、WIM、IMG 等镜像文件复制到 U 盘里就行，启动时 Ventoy 会识别所有镜像，列出菜单让你选。一个 U 盘可以同时放 Windows、Linux、PE 等多个系统，不用再像传统做法那样每换一个系统就格式化一次。

   从 [Ventoy 下载页](https://www.ventoy.net/en/download.html) 下载 Windows 版的压缩包。下载链接会跳到 SourceForge，文件由它托管。下载后解压到本地。

4. **安装 Ventoy**

   :::caution
   安装 Ventoy 会格式化你的 U 盘。请先把 U 盘里的重要文件备份出来，例如拷到电脑上。
   :::

   安装和配置的方法可以看这个视频：[BV1nj411w7R4](https://www.bilibili.com/video/BV1nj411w7R4/)。

   建议给 Ventoy 配置一个单独的镜像文件夹（例如 `SYSTEM`），不要把所有镜像都堆在 U 盘根目录，方便管理。

5. **把下载好的镜像放进这个文件夹**

6. **备份重要文件**

   重装系统会格式化硬盘，硬盘上的数据都会没掉，所以先把你自己的文件备份出来。可以用云端备份，但更建议备份到本地。装了 Ventoy 的 U 盘照样能存文件，镜像放在单独的文件夹里，就不会和备份混在一起。

7. **下载网卡驱动等驱动，拷到 U 盘**

   Windows 不一定自带你的无线网卡驱动，最好提前下载好放进 U 盘，这样装完系统就能连上 Wi-Fi。

   在搜索引擎里搜“设备型号 + 驱动下载”，大部分厂商会把驱动放在产品的支持页面上。如果找不到，可以向厂商提交反馈，请求适配你的设备。笔者手上这台就是提交反馈之后，厂商才补上的驱动下载。如果这些都不行，就去社区求助，一般也能解决。

   蓝牙驱动可以顺手一起下载。如果你觉得 Windows 自带的显示驱动不够用，或者你的 CPU 没有核显，也可以提前下载好显卡驱动。

   芯片组、音频、触控板等其他驱动可以按需下载。Windows 更新已经收录了大部分设备的大部分驱动，联网后它会扫描设备、自动补全，包括前面说的显卡驱动。

8. **其他注意事项**

   如果电脑里有多块硬盘，一定要分清哪块是机械硬盘（HDD）。系统装到机械硬盘上会非常慢，系统盘一定要用固态硬盘（SSD）。

   也可以把常用软件的安装包提前下好，例如 Chrome，这样装完系统不用打开 Edge 就能装软件。

9. **确认都准备好了**，接下来开始[安装 Windows](/system/windows/install)。

</Steps>
