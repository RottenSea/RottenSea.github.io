import { Steps } from "@astrojs/starlight/components";

这一步开始真正地净化 Windows。重启后连上网络，按 <kbd>Win</kbd> + <kbd>I</kbd> 打开设置。

<Steps>

1. **卸载预装软件**

   进入 **设置 > 应用 > 已安装的应用**，卸载不需要的应用，包括 OneDrive。

   :::note
   建议保留“反馈中心”（Feedback Hub）这类基础应用，微软的部分服务依赖它们。
   :::

2. **让 Windows 更新装驱动，顺便加上英语**

   联网后，Windows 更新会自动开始搜索和下载驱动，不用手动去点。装显卡驱动时（是的，就算你自己装过，Windows 为了兼容性还会再装一遍），屏幕会闪几下，这是正常的。

   这段时间可以继续做别的设置，建议先把英语加上：进入 **设置 > 时间和语言 > 语言和区域**，点击“添加语言”，搜索“英语”。英语有很多地区变体，按喜好选英式或美式英语就行。驱动下载完后，Windows 会接着下载语言包。

   笔者建议把英语排到第一位，默认用英文输入法。中文输入法自带的快捷键经常和其他操作冲突，让 Windows 变得不顺手。按 <kbd>Win</kbd> + <kbd>Space</kbd> 切换输入法。

3. **整理开始菜单**

   按 <kbd>Win</kbd> 键打开开始菜单。笔者建议把常用的快捷方式都固定到开始菜单里，在任何地方都能快速打开；同时删掉桌面上的快捷方式，保持桌面整洁。

   所有快捷方式都能在资源管理器里找到：

   - 当前用户的开始菜单：`%APPDATA%\Microsoft\Windows\Start Menu\Programs`
   - 所有用户的开始菜单：`%ALLUSERSPROFILE%\Microsoft\Windows\Start Menu\Programs`

   :::tip
   整理开始菜单是用 Windows 一直要做的事，装了新软件就顺手整理一下。
   :::

4. **个性化**

   - **设置 > 个性化 > 动态光效**：关掉“在我的设备上使用动态光效”和“前台兼容应用始终控制光效”。
   - **设置 > 个性化 > 锁屏界面**：“个性化锁屏界面”选“图片”，“锁屏界面状态”选“无”，锁屏上就不会再出现广告和资讯。
   - **设置 > 个性化 > 开始**：关掉“显示最近添加的应用”“在开始、文件资源管理器和跳转列表中显示推荐的文件”“显示提示、快捷方式、新应用等推荐”和“显示与帐户相关的通知”。
   - **设置 > 个性化 > 任务栏**：在“任务栏项”里，“搜索”选“仅搜索图标”，关掉“任务视图”“小组件”和“恢复”（Resume）。

5. **系统**

   - **显示**：一块屏幕能显示的内容总是有限的，笔者倾向于把缩放调小，显示更多内容，很多时候能帮你获取更多信息。笔者还会把刷新率固定在 60 Hz，省一些电。
   - **通知**：在“自动开启请勿打扰”里，取消勾选“功能更新后的第一个小时”。
   - **电源和电池**：在“节能模式”里关掉“使用节能模式时降低屏幕亮度”。
   - **多任务处理**：“贴靠窗口”保持打开，但把下面五个子选项全部取消勾选；“贴靠或按 Alt+Tab 时显示应用中的标签页”选“不显示标签页”。
   - **高级**：打开下面四项。
     - 任务栏里的“结束任务”（End Task）：右键任务栏图标就能结束任务。
     - “启用长路径”（Enable long paths）：去掉 Win32 文件函数 260 个字符的路径长度限制。
     - PowerShell 下的“更改执行策略，允许本地 PowerShell 脚本无需签名即可运行”：不打开的话，很多脚本在 PowerShell 里跑不了。用 `Get-ExecutionPolicy -List` 可以查看当前生效的执行策略。
     - “开发人员模式”（Developer Mode）：允许从任何来源安装应用，包括松散文件。
   - **激活**：按 <kbd>Win</kbd> + <kbd>X</kbd> 打开高级用户菜单，选择以管理员身份运行终端，依次输入下面的命令，用第三方 KMS 服务器“合法地”激活 Windows：

     ```powershell
     slmgr /ipk W269N-WFGWX-YVC9B-4J6C9-T83GX
     slmgr /skms kms.03k.org
     slmgr /ato
     ```

6. **设备**

   进入 **设置 > 蓝牙和其他设备 > 触控板 > 点击**，把“三指点击”改成“鼠标中键”，更符合直觉。其他设置按自己的喜好调整就好。

7. **游戏**

   进入 **设置 > 游戏 > 游戏模式**，把它关掉。游戏模式会优先把系统资源分给游戏，如果你不玩游戏，或者更在意后台程序的性能，关掉它可以避免资源调度带来的干扰。

8. **辅助功能**

   关掉这些容易误触的快捷键：

   - **对比度主题**：“对比度主题的键盘快捷方式”（左 <kbd>Alt</kbd> + 左 <kbd>Shift</kbd> + <kbd>PrtSc</kbd>）。
   - **讲述人**：“讲述人的键盘快捷方式”（<kbd>Win</kbd> + <kbd>Ctrl</kbd> + <kbd>Enter</kbd>）。
   - **键盘 > 粘滞键**：粘滞键的键盘快捷方式（连按五次 <kbd>Shift</kbd>）。
   - **键盘 > 筛选键**：筛选键的键盘快捷方式。

   再到 **视觉效果** 里关掉“动画效果”。这是个人喜好，但很实用，操作会更跟手。笔者在这一页还关了“透明效果”，打开了“始终显示滚动条”。

9. **隐私**

   进入 **设置 > 隐私和安全性 > 位置**，关掉“应用请求位置时通知”。

</Steps>

到这里，系统设置部分就差不多完成了。下一步：[用 WinUtil 清理](/system/windows/winutil)。
