import { Steps } from "@astrojs/starlight/components";

重启后连上网络，按 <kbd>Win</kbd> + <kbd>I</kbd> 打开设置。运行过[设置脚本](/system/windows/script)的话，标着“脚本已经做了”的项可以跳过。

<Steps>

1. **卸载预装软件**

   进入 **设置 > 应用 > 已安装的应用**，卸载不需要的应用，包括 OneDrive。

   :::note
   “反馈中心”（Feedback Hub）这类基础应用建议保留，微软的部分服务依赖它们。
   :::

2. **让 Windows 更新装驱动，加上英语（可选）**

   联网后，Windows 更新会自动搜索和下载驱动。装显卡驱动时，即使你自己装过，Windows 为了兼容性也可能再装一遍，屏幕会闪几下，这是正常的。

   这段时间可以加上英语：进入 **设置 > 时间和语言 > 语言和区域**，点击“添加语言”，搜索“英语”，选英式或美式英语都行。驱动下载完后，Windows 会接着下载语言包。

   把英语排到第一位，默认就是英文输入法。中文输入法自带的快捷键（例如切换全角半角、简繁体）在别的程序里容易误触，默认用英文输入法可以避开；要打中文时按 <kbd>Win</kbd> + <kbd>Space</kbd> 切换。习惯默认中文输入的话，这一步可以跳过。

3. **整理开始菜单**

   把常用的快捷方式固定到开始菜单里，在任何地方按 <kbd>Win</kbd> 都能快速打开；桌面上的快捷方式可以删掉。

   所有快捷方式都能在资源管理器里找到：

   - 当前用户的开始菜单：`%APPDATA%\Microsoft\Windows\Start Menu\Programs`
   - 所有用户的开始菜单：`%ALLUSERSPROFILE%\Microsoft\Windows\Start Menu\Programs`

   装了新软件，顺手把它的快捷方式整理进去。

4. **个性化**

   脚本已经做了：关掉动态光效（`dynamic-lighting`）、锁屏的 Windows 聚焦和提示（`lock-screen`）、开始菜单的推荐（`start-suggestions`），任务栏的搜索改成图标、去掉任务视图按钮（`taskbar-buttons`），删掉小组件（`widgets`）。

   <details>
   <summary>手动设置</summary>

   - **设置 > 个性化 > 动态光效**：关掉“在我的设备上使用动态光效”和“前台兼容应用始终控制光效”。
   - **设置 > 个性化 > 锁屏界面**：“个性化锁屏界面”选“图片”。
   - **设置 > 个性化 > 开始**：关掉“在开始、文件资源管理器和跳转列表中显示推荐的文件”“显示提示、快捷方式、新应用等推荐”和“显示与帐户相关的通知”。
   - **设置 > 个性化 > 任务栏**：在“任务栏项”里，“搜索”选“仅搜索图标”，关掉“任务视图”和“小组件”。

   </details>

   这几项脚本做不了，要手动改：

   - **设置 > 个性化 > 锁屏界面**：“锁屏界面状态”选“无”。
   - **设置 > 个性化 > 开始**：关掉“显示最近添加的应用”。
   - **设置 > 个性化 > 任务栏**：关掉“恢复”（Resume）。

5. **系统**

   脚本已经做了：任务栏右键“结束任务”（`end-task`）、启用长路径（`long-paths`）、允许本地 PowerShell 脚本运行（`script-policy`）、开发人员模式（`developer-mode`）。

   <details>
   <summary>手动设置</summary>

   进入 **设置 > 系统 > 高级**，打开下面四项：

   - 任务栏里的“结束任务”（End Task）：右键任务栏图标就能结束任务。
   - “启用长路径”（Enable long paths）：去掉 Win32 文件函数 260 个字符的路径长度限制。
   - PowerShell 下的“更改执行策略，允许本地 PowerShell 脚本无需签名即可运行”：不打开的话，很多脚本在 PowerShell 里跑不了。用 `Get-ExecutionPolicy -List` 可以查看当前生效的执行策略。
   - “开发人员模式”（Developer Mode）：允许从任何来源安装应用，包括松散文件。

   </details>

   这几项脚本做不了，要手动改：

   - **显示（可选）**：缩放调小，一屏能显示更多内容；刷新率固定在 60 Hz 能省一些电。按自己的屏幕和习惯定。
   - **通知**：在“自动开启请勿打扰”里，取消勾选“功能更新后的第一个小时”。
   - **电源和电池**：在“节能模式”里关掉“使用节能模式时降低屏幕亮度”。
   - **多任务处理**：“贴靠窗口”保持打开，把下面五个子选项全部取消勾选；“贴靠或按 Alt+Tab 时显示应用中的标签页”选“不显示标签页”。
   - **激活**：按 <kbd>Win</kbd> + <kbd>X</kbd> 打开高级用户菜单，选择以管理员身份运行终端，依次输入下面的命令，用第三方 KMS 服务器“合法地”激活 Windows：

     ```powershell
     slmgr /ipk W269N-WFGWX-YVC9B-4J6C9-T83GX
     slmgr /skms kms.03k.org
     slmgr /ato
     ```

6. **设备**

   进入 **设置 > 蓝牙和其他设备 > 触控板 > 点击**，把“三指点击”改成“鼠标中键”。其他设置按自己的习惯调整。

7. **游戏**

   脚本已经关掉了游戏模式（`game-mode`）。游戏模式会优先把系统资源分给游戏；不玩游戏，或者更在意后台程序的性能时，关掉它。

   <details>
   <summary>手动设置</summary>

   进入 **设置 > 游戏 > 游戏模式**，把它关掉。

   </details>

8. **辅助功能**

   脚本已经关掉了容易误触的辅助功能快捷键（`accessibility-shortcuts`）、透明效果（`transparency`），并让滚动条始终显示（`scrollbars`）。

   <details>
   <summary>手动设置</summary>

   关掉这些快捷键：

   - **对比度主题**：“对比度主题的键盘快捷方式”（左 <kbd>Alt</kbd> + 左 <kbd>Shift</kbd> + <kbd>PrtSc</kbd>）。
   - **讲述人**：“讲述人的键盘快捷方式”（<kbd>Win</kbd> + <kbd>Ctrl</kbd> + <kbd>Enter</kbd>）。
   - **键盘 > 粘滞键**：粘滞键的键盘快捷方式（连按五次 <kbd>Shift</kbd>）。
   - **键盘 > 筛选键**：筛选键的键盘快捷方式。

   再到 **视觉效果** 里关掉“透明效果”，打开“始终显示滚动条”。

   </details>

   **视觉效果** 里的“动画效果”（可选）脚本不改：关掉以后窗口打开、关闭和切换没有动画，操作更跟手，但看起来更生硬，按喜好定。

9. **隐私**

   进入 **设置 > 隐私和安全性 > 位置**，关掉“应用请求位置时通知”。

</Steps>

脚本的“系统优化”一组还关掉了遥测、广告和几个后台服务，每一项改了什么见[设置脚本](/system/windows/script)。最后一页是[推荐的软件](/system/windows/apps)。
