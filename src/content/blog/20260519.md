## Vibe Coding

### 什么是 Vibe Coding

**Vibe Coding（氛围编程）** 是一种由AI驱动的全新编程范式，开发者通过**自然语言**向AI描述需求和“感觉”，AI则负责自动生成、修改和调试代码。

Vibe Coding 的形态在过去与现在有着显著不同。早期，它主要体现为 VS Code 的插件，核心功能是智能的行内代码补全。然而，随着这一概念的兴起，Vibe Coding 的工具边界被极大拓宽：它们不仅能调用更多系统权限，还能处理更复杂的开发任务。以 Cursor 和 Claude Code 为代表的工具便是其中的佼佼者。值得一提的是，这类工具虽然本身闭源，但开放了 API 接口，允许用户替换为 DeepSeek 等第三方模型，这也让国内用户能够便捷地使用。

### Vibe Coding 与传统网页对话有什么不同

| 技术维度         | 网页对话                                                    | Vibe Coding                                                        |
| ---------------- | ----------------------------------------------------------- | ------------------------------------------------------------------ |
| **代码执行能力** | 无。模型生成代码后，需要你**手动复制**到本地运行。          | **自动执行**。AI 可以直接在终端运行你生成的代码。                  |
| **反馈闭环**     | 你看到错误 → 手动复制错误信息 → 手动粘贴回复 → 让 AI 再改。 | **错误自动回传**。终端报错自动喂给 AI，AI 自动修正。               |
| **文件系统访问** | 无。AI 不知道你的项目有哪些文件、目录结构。                 | **可读写文件**。AI 可以自己创建、修改、删除项目中的多个文件。      |
| **工具调用能力** | 无。模型只能输出文本。                                      | **有函数调用**。AI 可以主动执行 shell 命令、git 操作、运行测试等。 |
| **交互方式**     | 一问一答，手动复制粘贴。                                    | **多轮自动循环**。AI 自己写 → 跑 → 看报错 → 改 → 再跑，直到完成。  |

Vibe Coding 通过上下文提示词给予了AI调用外部工具、读取文件、修改文件等功能。

## 为什么尝试 Vibe Coding？

![Vibe Coding](@/assets/images/2026051900.png)
根据我大量在线学习的经历，诚然，对我而言，学习是一个在大脑中创建索引与链接的过程，在遇到一个问题的时候，如果你能够索引到解决方案，那你就可以解决这个问题。如何创建索引？这是一个搜索相关文档并总结归纳地过程：你需要在搜索引擎搜索关键词，并翻阅各个网站或者官方文档。而AI的出现，让索引的创建变得异常容易，往往只需要一个提问，你就能够在脑海中创建解决问题的索引并持续深入，省去了大量的搜索的时间。而且给了AI一只"笔”并告诉它如何使用之后，AI还能够帮助你快速完成任务，效率得到了巨大的提升。

如果你有自己想要尝试做到的事情，但是不知从何开始，不妨尝试一下Vibe Coding。

没有清晰的参考文档，没有 SOP （**Standard Operating Procedure**） 的事情。

## 如何看待 Vibe Coding

不要问 AI 能帮你做什么，要问你想做什么。然后把 AI 当作自己，直接去实现，AI时代下，人人都能利用 AI 做自己想做的事情。
