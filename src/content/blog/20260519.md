## Vibe Coding

### 什么是 Vibe Coding

**Vibe Coding (氛围编程)** 是一种由 AI Agent 驱动的全新编程范式, 开发者通过**自然语言**向 Agent 描述需求, Agent 则负责自动生成, 修改和调试代码.

Vibe Coding 的形态在过去与现在有着显著不同. 早期, 它主要体现为 VS Code 的插件, 核心功能是智能的行内代码补全. 然而, 随着这一概念的兴起, Vibe Coding 的工具边界被极大拓宽: 它们不仅能调用更多系统权限, 还能处理更复杂的开发任务. 以 Cursor 和 Claude Code 为代表的 Agent 编程工具便是其中的佼佼者. 值得一提的是, 这类工具虽然本身闭源, 但开放了 API 接口, 允许用户替换为 DeepSeek 等第三方模型, 这也让中国国内用户能够便捷地使用.

### AI Agent 与传统网页对话有什么不同

| 技术维度 | 网页对话 | AI Agent |
| ---------- | ------------------------------------ | --------------------------------------------- |
| **代码执行能力** | 无. 模型生成代码后, 需要你**手动复制**到本地运行. | **自动执行**. Agent 可以直接在终端运行你生成的代码. |
| **反馈闭环** | 你看到错误 → 手动复制错误信息 → 手动粘贴回复 → 让 AI 再改. | **错误自动回传**. 终端报错自动喂给 Agent, Agent 自动修正. |
| **文件系统访问** | 无. AI 不知道你的项目有哪些文件, 目录结构. | **可读写文件**. Agent 可以自己创建, 修改, 删除项目中的多个文件. |
| **工具调用能力** | 无. 模型只能输出文本. | **有函数调用**. Agent 可以主动执行 shell 命令, git 操作, 运行测试等. |
| **交互方式** | 一问一答, 手动复制粘贴. | **多轮自动循环**. Agent 自己写 → 跑 → 看报错 → 改 → 再跑, 直到完成. |

Vibe Coding 工具的本质是一个 AI Agent -- 通过提示词被赋予了调用外部工具, 读取文件, 修改文件等能力.

## 为什么尝试 Vibe Coding?

![展示 With AI 和 Without AI 两种模式下工作流程对比的示意图](@/assets/images/2026051900.png)

根据笔者大量在线学习的经历, 诚然, 对笔者而言, 学习是一个在大脑中创建索引与链接的过程, 在遇到一个问题的时候, 如果你能够索引到解决方案, 那你就可以解决这个问题. 如何创建索引? 在之前, 这是一个搜索相关文档并总结归纳地过程: 你需要在搜索引擎搜索关键词, 并翻阅各个网站或者官方文档. 而 AI 的出现, 让索引的创建变得异常容易, 往往只需要一个提问, 你就能够在脑海中创建解决问题的索引并持续深入, 省去了大量的搜索的时间. 而且给了 AI 一只 "笔" 并告诉它如何使用之后, AI 还能够帮助你快速完成任务, 效率得到了巨大的提升.

如果你有自己想要尝试做到的事情, 但是不知从何开始, 不妨尝试一下 Vibe Coding.

## 有哪些成熟的 Vibe Coding Agent

在所有情况下, 笔者都建议使用终端, 也就是**命令行环境下的编程 Agent**, 因为 CLI Agent 的可自定义程度更高.

| cli | description |
| ---------------------- | --------------------------------------- |
| Claude Code CLI | "最强 coding agent CLI" |
| Codex CLI | OpenAI 版 Claude Code 有免费试用 |
| Google Antigravity CLI | 良心 Google 有免费试用 |
| OpenCode CLI | 开源 官方 OpenCode Zen 免费供应部分模型 |
| Aider | 开源 需要自行接入外部模型 |
| Goose | 开源 需要自行接入外部模型 |

### 哪一个组合效果最佳?

![Cursor 深色主题 AI 代码编辑器界面截图, 展示左侧侧边栏菜单和底部命令输入区域](@/assets/images/2026051902.png)

在以前, 笔者可能会认为 Claude Code + Claude Opus 是最强的, 但是后来发现 Claude 和 ChatGPT 都有各自的优势. Claude 思维发散能力很强, ChatGPT 编写代码的能力胜过 Claude, Claude 和 ChatGPT 都使用才是最佳搭配, Claude 适合做 CEO, ChatGPT 适合做 CTO.

### 想知道哪个 AI 模型的使用效果好?

![Text Arena 网站编程类别 AI 模型排行榜, 列出各模型排名, 分数及价格](@/assets/images/2026051901.png)

[Arena AI](https://arena.ai/) 运营公开的**大模型竞技场排行榜**. 它让用户匿名, 并排对比两个模型的回答 (A/B 测试), 基于海量真实用户投票进行排名. 排行榜包含文本, 编程, 视觉理解等方面.

![Artificial Analysis 发布的代码智能体性能分析图表, 对比各主流 AI 模型排名数据](@/assets/images/2026051903.png)

[Artificial Analysis](https://artificialanalysis.ai/) 是一个专注于**独立分析, 评测和对比 AI 模型与 API 提供商**的专业数据平台. 分数很难受到人工干预, 更加客观.

## 什么事情不适合使用 AI

没有清晰的参考文档, 没有 SOP (**Standard Operating Procedure**) 的事情.

## 如何看待 Vibe Coding

不要问 Agent 能帮你做什么, 要问你想做什么.
