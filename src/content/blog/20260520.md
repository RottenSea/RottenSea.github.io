## 预准备

1. 确保你已经安装了 git
2. 一个国际的网络环境，不在本文讨论范围，故不赘述。

## 安装

详情请参考 [OpenCode 官方文档](https://opencode.ai/docs/#install)

由于 OpenCode 官方的教程是 Linux & MacOS 友好，这里介绍一下 OpenCode 在 Windows 平台下的一种简单的安装方式（当然你也可以根据教程使用 node.js 和 pnpm 进行安装）。

1. 前往 OpenCode 在 Github 上的[仓库](https://github.com/anomalyco/opencode)
2. 找到最新的 Release 并访问
3. 在 Release description 下方找到 `opencode-windows-x64.zip`（往往在最后）
4. 单击并下载压缩包
5. 下载完成后在资源管理器中找到刚刚下载的文件并解压
6. 将解压出来的 exe 文件放置在你认为可以作为环境存储的目录下（不建议需要管理员权限的目录），推荐 `%USERPROFILE%\.local\bin` 目录
7. 将 `%USERPROFILE%\.local\bin` 目录添加到系统环境变量当中
8. 使用 powershell 运行 `opencode -v` ，检查能否成功启动 OpenCode

安装完成。

与其说是安装，不如描述为将一个 exe 文件添加到环境变量当中。

### Troubleshooting

| question               | discription                                                                                                                                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Github下载很慢         | 检查是否处于国际网络环境                                                                                                                                                                                            |
| 什么是 `%USERPROFILE%` | 这是一个环境变量，如果你的用户名是 `Zhang`，那么 `%USERPROFILE%` = `C:\Users\Zhang`，你可以在powershell中尝试输入此环境变量，查看该变量的值。你可以在资源管理器的地址栏中输入该变量，以达到快速访问目标目录的目的。 |

### 如何将目标目录添加到环境变量当中？

1. 打开环境变量窗口

- 方法一

使用 `` + `S` 快捷键，打开搜索框，输入 `edit environment variables for your account` （系统语言英文）或 `编辑环境变量` （系统语言中文），你应该能够搜索到相关结果。

![环境变量](@/assets/images/2026052001.png)

- 方法二

使用 `` + `R` 快捷键，打开运行窗口，输入 `sysdm.cpl` 并按下 `⏎` ，现在你应该打开了编辑环境变量窗口。

2. 复制你放置 exe 文件的路径

![Path编辑](@/assets/images/2026052002.png)

3. 在环境变量窗口中，选中 `Path` ，点击 `Edit` ，在新窗口中点击 `New` 将你刚刚复制的内容粘贴进聚焦的输入框中，按下 `⏎` ，点击新窗口下方的 `确定` ，点击环境变量窗口下方的确定。

你成功将一个路径添加到了环境变量当中。

## 如何使用 OpenCode？

1. 打开资源管理器，导航到你想要让 OpenCode 工作的目录（建议使用空文件夹，请不要选择桌面等路径，除非你知道你在做什么）
2. 在资源管理器空白处右键，选择在终端中打开（注意不要选中任何文件夹中的项目）

![终端打开](@/assets/images/2026052003.png)

3. 在终端中输入 `opencode` 并按下 `⏎` ，这样你就能够开始使用 OpenCode 了

## 熟悉 OpenCode

## 快捷键

1. `ctrl` + `C` 退出 OpenCode ，回到终端
2. `ctrl` + `P` 打开指令面板
3. `Escape` + `Escape` 终端 OpenCode 的执行

### OpenCode 命令行指令

1. `opencode` 打开 OpenCode（新对话）
2. `opencode -c` 打开 OpenCode（继续上次对话）
3. `opencode -v` 输出当前 OpenCode 版本
4. `opencode upgrade` 在线更新 OpenCode（不是使用官方方式安装的 opencode 不在版本控制当中，如果你的 OpenCode 是按照这篇博客的方式安装的，请前往 GitHub 下载并覆盖旧版本文件）

### 对话指令

直接在对话框输入 `/` 可以触发指令

1. `/providers` 链接外部供应商 api
2. `/models` 能够在能够使用的模型之间切换
3. `/themes` 切换主题
4. `/sessions` 能够查看在当前目录的历史对话，如果你发现你的历史对话不见了，大概率是目录不同导致的
5. `/skills` 查看安装的 skills
6. `/undo` 撤销上一次消息 OpenCode 所做的操作（注意：如果你的文件是当次消息新加入的，可能导致OpenCode追踪不全，误删文件，执行前请先备份）

更详细的使用方式，请参照[OpenCode 官方文档](https://opencode.ai/docs)

## Vibe Coding 使用场景

编程是这类工具的主要用途，但是不仅限于编程，正如上面所演示的，OpenCode 还能够执行终端的命令。拥有执行终端命令的能力就说明， OpenCode 几乎能够帮你做到任何事情，例如帮你安装 python 环境，帮你跑起来一个github上的项目。终端是强大的，许多 Linux 开发者仅使用终端的功能进行开发，在终端中就能执行指令，浏览目录，修改文件。

但是帮你完成 Unity 项目，PS 修改图片， AE 制作合成这类事情还是无法做到的，因为没有对应的接口。有接口的，例如 Word、Excel、PowerPoint 这些都能够接入 AI，并让 AI 直接帮助你完成任务。
