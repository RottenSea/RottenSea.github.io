## 你是系统的主人

作为多年的 Windows 老用户，我对系统操作早已形成了一套自己的习惯。然而，每当需要帮别人处理计算机问题时，面对那些“陌生”的设置——Win11 那层层折叠的右键菜单、臃肿杂乱的任务栏——总让我有种无力感。

一个有趣的事实，许多 PC 厂商都在自带的 Windows 系统中添加了很多服务自身服务的预装软件与进程。

拿华硕来举例,会在原有windows系统上预装以下但不仅限于以下软件（不包括驱动）。

管家这类软件根本没有什么用途，应用商店不知道在 cos 什么，窗口管理工具打破了原有的操作流畅感，后面三个预装软件对与笔者来说没有用途或有更好的替代品。

至于恢复备份工具，我们都能自己重装系统了还需要他的恢复有什么用。恢复功能 windows 也自带了，可以手动创建还原点.如果使用官方的一键恢复功能，恢复后，又给你装一堆预装软件。备份自己管理就行，无非就是文件从一个地方拷贝到另一个地方，用不着软件来管理。

综合来看，这一大堆预装软件，服务，基本没有什么用途，还占用了大量 CPU 和内存。

好在，Windows 有一定可塑性。这篇文章，我想和你分享几招让 Windows 回归顺手、好用的个性化定制方案。

## 概要

让 Windows 更好用，首先要选择正确的系统。

![[Screenshot 2026-06-18 064337 1 1.png]]

使用`winenv`可以查看 当前Windows 的安装信息，一般 PC 厂商出厂给的Windows 系统是 Windows Home (家庭版)，而不是 Windows Pro(专业版)。这两个版本基本功能区别不大，但是 Pro 版开放了更多的可配置选项，例如 Group Policy （组策略编辑器），远程桌面连接（被控端），Hyper-V 虚拟机。

Windows 的很多功能是可以通过设置或者注册表来管理的，例如右键菜单，可以通过注册表恢复成 旧版 右键菜单。部分不需要的功能也能够被禁用掉。

所以一个好用的Windows系统实际上就是摆脱原厂客制化系统的纯净原版Windows系统加上大量的配置，以下是安装 Windows与进行配置的详细教程，阅读可能需要一定的时间。

## 安装纯净版 Windows

1. 备份你的所有文件

将你自己管理的文件，备份到其他地方，应为系统重装会格式化磁盘，导致数据不可用。可以使用云端备份但是建议使用本地备份。

2. 下载Windows镜像

- 前往微软官方的 [Windows ISO 下载页面](https://www.microsoft.com/en-us/software-download/windows11)

![[Pasted image 20260618084543.png]]

- 在最后找到下载 ISO 镜像文件，选择 Windows 镜像与国家最后点击下载
- 等待下载完成，这样你就得到了微软官方的 Windows ISO 镜像文件

3. 将U盘制作为启动盘

- Ventoy
Ventoy 是一款开源免费的启动 U 盘制作工具。它的核心特点是安装一次后，你就可以直接把 ISO、WIM、IMG 等系统镜像文件复制到 U 盘里，启动时 Ventoy 会自动识别所有镜像并显示菜单供你选择。这意味着一个 U 盘可以同时存放多个系统，支持 Windows、Linux、PE 等多种镜像，改变了传统制作系统盘的反复格式化问题。

- 从[Ventoy下载页](https://www.ventoy.net/en/download.html)下载Ventoy安装程序到本地

![[Screenshot 2026-06-18 085732.png]]

点击下载链接会导航到外部下载页，Source Forge 会托管文件提供下载。

- 安装Ventoy

> 注意！安装Ventoy会格式化你的U盘，请提前将U盘内的重要文件进行备份，例如拷贝到PC中.
